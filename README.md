# Medusa Digital Painting

An animated digital painting project created using Python.

## Features

- Animated sketch drawing
- Original full-color Medusa painting
- Turquoise drawing effects
- Smooth color reveal
- Shimmer and sparkle effects
- Animated quotation

## Technologies

- Python
- Pygame CE
- OpenCV
- NumPy

## Installation

Install dependencies:

pip install -r requirements.txt

## Run

python main.py

## Controls

R - Restart animation
ESC - Exit
